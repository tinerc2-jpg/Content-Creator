## 4. Spilleregler for hvert opslag

1. **Hook i linje 1–2.** Under 15 ord. Det er det eneste, folk ser før "…se mere".
2. **Én pointe pr. opslag.** 800–1.500 tegn er nok.
3. **Luft.** Korte afsnit, én tanke pr. linje.
4. **Slut med et spørgsmål**, der er nemt at svare på.
5. **Ingen eksterne links i selve opslaget** – læg dem i første kommentar.
6. **0–3 hashtags**, fx `#HR` `#Rekruttering` `#Ledelse`.
7. **Udgiv tirsdag–torsdag kl. 7.30–9.00**, og svar på alle kommentarer inden for den første time.
8. **Brug 15 minutter dagligt** på at kommentere hos andre HR-folk og rekrutterere. Det skaber lige så meget synlighed som dine egne opslag.

## 5. Det måler vi på (grundlaget for dashboardet)

For hvert opslag registrerer vi efter **48 timer** og igen efter **7 dage**:

| Måltal | Hvor finder du det |
|--------|--------------------|
| Visninger (impressions) | Opslag → "Vis analyse" |
| Unikke seere (members reached) | Samme sted |
| Reaktioner, kommentarer, genopslag | Samme sted |
| Gemte og sendte | Samme sted |
| Profilvisninger fra opslaget | Samme sted |
| Nye følgere | Samme sted |
| **Engagementsrate** = (reaktioner + kommentarer + genopslag) / visninger | Beregnes i dashboardet |
| Rekrutterer-henvendelser / samtaler | Noterer du selv |

Data samles i [`data/posts.csv`](../data/posts.csv), som dashboardet læser fra.
